Quick start

Kalangu builds AI agents that work on any phone, keypad phones included, over USSD and SMS. This page gets you from nothing to an agent you can talk to in a few minutes, with no account and no API key.

You need Node 20 or later.

1. See it work#

Clone the repository and run the demo:

git clone https://github.com/utachicodes/kalangu.git
cd kalangu
pnpm install
pnpm demo

A keypad phone appears in your terminal. Dial *384*1#, choose 2, and ask a question. The example's fake nurse takes 6 seconds and the deadline is 4, so the screen says the answer will come by SMS, and a couple of seconds later it does. x hangs up mid-session (dial again to resume), sms <text> texts the agent, q quits.

With a real model. Install Ollama, pull a model and run the demo with it:

ollama pull llama3.2
OLLAMA_MODEL=llama3.2 pnpm demo

Ask anything now; a local model usually takes more than 4 seconds, so most answers come by SMS. If Ollama runs on another machine, set OLLAMA_HOST too, for example OLLAMA_HOST=192.168.1.20:11434.

Or with Gemini, using an API key from Google AI Studio (it starts with AIza). Export it in your shell without typing it on the command line, so it stays out of your history:

read -s GEMINI_API_KEY && export GEMINI_API_KEY   # paste the key; nothing is shown
GEMINI_MODEL=gemini-3.5-flash-lite pnpm demo

Only the question and the nurse's instructions go to Google, never the caller's number. Never paste the key into a chat, an issue or a file in the repository.

2. Write your first agent#

In a new folder:

npm init -y
npm pkg set type=module
npm install @kalangu/core @kalangu/sim

Create agent.mjs:

import { ask, createAgent, menu, say } from "@kalangu/core";

// Any object can be the model: handlers receive it as ctx.model.
const model = {
  async answer(question) {
    return `You asked: ${question}`;
  },
};

export const agent = createAgent({
  model,
  channels: [], // the simulator brings its own; real channels come in step 4
  start: menu("Clinic line", {
    "Opening hours": say("Open Monday to Saturday, 8:00 to 18:00."),
    "Ask a nurse": ask("Type your question", (question, ctx) => ctx.model.answer(question)),
  }),
});

3. Talk to it#

Create try.mjs, which drives the agent with a simulated phone:

import { createPhone } from "@kalangu/sim";
import { agent } from "./agent.mjs";

const phone = createPhone(agent, { code: "*384*1#" });

console.log(await phone.dial("*384*1#"));
console.log(await phone.press("2"));
console.log(await phone.press("Is the clinic open on Sunday?"));

Run it with node try.mjs:

{ text: 'Clinic line\n1. Opening hours\n2. Ask a nurse', end: false }
{ text: 'Type your question', end: false }
{ text: 'You asked: Is the clinic open on Sunday?', end: true }

Each line is one USSD screen. end: true means the session is over. To use the keypad in your terminal instead, run import { runTerminal } from "@kalangu/sim"; await runTerminal(agent, { code: "*384*1#" });.

To answer with Ollama instead of echoing, make answer call its chat API:

const model = {
  async answer(question) {
    const res = await fetch("http://localhost:11434/api/chat", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({
        model: "llama3.2",
        stream: false,
        options: { num_predict: 150 },
        messages: [
          { role: "system", content: "You answer clinic questions sent from basic phones. Plain text, at most 2 short sentences." },
          { role: "user", content: question },
        ],
      }),
    });
    if (!res.ok) throw new Error(`Ollama answered ${res.status}`);
    return (await res.json()).message.content.trim();
  },
};

Keep answers short: a long answer is split across USSD screens, which is fine, but an SMS reply over 4 segments is an error, never cut. The example's ollama.ts shortens to fit, strips formatting, and apologises when Ollama is down. Ollama must be reachable from wherever the agent runs, so not from a serverless host unless you expose it.

4. Put it on a real gateway#

Add the Africa's Talking channels and serve the agent:

npm install @kalangu/ussd @kalangu/sms

import { africasTalkingSms } from "@kalangu/sms";
import { africasTalkingUssd } from "@kalangu/ussd";

export const agent = createAgent({
  model,
  channels: [
    africasTalkingUssd({ code: "*384*1#", path: "/ussd" }),
    africasTalkingSms({ username: "sandbox", apiKey: process.env.AT_API_KEY, sandbox: true, path: "/sms" }),
  ],
  start: /* as before */,
});

agent.requestHandler is a standard Request to Response function, so it runs anywhere that serves one: for example Bun.serve({ fetch: agent.requestHandler }) or Deno.serve(agent.requestHandler). For Node's http module, copy the small adapter in examples/clinic/src/server.ts.

To try it on Africa's Talking's free sandbox with their phone simulator, follow the sandbox guide.
