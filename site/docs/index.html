Kalangu documentation

Kalangu is an open-source TypeScript toolkit for AI agents that work on any phone, keypad phones included, over USSD and SMS. Packages are published on npm as alpha releases: the API may change before 1.0.

Start here#

  • Quick start: from nothing to an agent you can talk to in a few minutes, with no account and no API key.
  • Agents: steps, handlers, sessions, slow answers, languages, payments, channels, testing, and what to set before production.
  • Providers: plug in a model (Ollama, Claude, Gemini, any API in OpenAI's format) and gateways, several at once.

Guides#

  • Run on the Africa's Talking sandbox: the real gateway, with their phone simulator.
  • Translate Kalangu: a new language for the fixed strings, checked for USSD and SMS.
  • Measure a language detector: accuracy on short text, and the threshold to use, from your own samples.
  • Release the packages: for maintainers.

Design#

Kalangu is designed in the open, and the design documents explain why it works the way it does, including what has not been verified yet.

  • Core design: turns, the budgeter, deferral, adapters.
  • Payments: experimental, against a fake provider.
  • Languages: the language menu, detection, models.
  • WhatsApp: designed, not built.
  • Text normalization: African languages on keypads and USSD.
  • Prior art: what else exists.
