For phones without internet, and voices without keyboards

The components

Buttons, tabs and toasts you can get anywhere. These are the pieces we could not find while building the Ndiédieng example: what an SMS really costs before you send it, what a USSD menu looks like on a keypad phone, and voice that keeps working when browsers don't.

Each demo runs from exactly the code under it, two of them on Kalangu itself. Plain HTML, CSS and JavaScript, no framework. MIT, like the rest of Kalangu.
